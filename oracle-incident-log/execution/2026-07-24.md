- [2026-07-24 08:49:23] `DB_FILE_NAME_CONVERT` 하위 절 설명
  - 질문 맥락: RMAN 연습장에서 `BACKUP` 다음 후보로 표시되는 `DB_FILE_NAME_CONVERT`가 무엇인지 문의함.
  - 에러 메시지: 없음. 정확한 키워드는 끝에 `T`가 포함된 `DB_FILE_NAME_CONVERT`임.
  - 원인 가설: 이 키워드는 일반 백업 피스 이름을 지정하는 `FORMAT`과 달리, 기존 데이터파일 이름의 문자열을 치환하여 새 출력 파일명을 만드는 `fileNameConversionSpec`이므로 용도가 직관적이지 않음.
  - 권장 조치: 주로 `BACKUP AS COPY` 이미지 복사본에서 `(원본문자열, 대체문자열)` 쌍을 짝수 개 지정함. RMAN은 원본 파일명에서 첫 번째로 일치한 원본문자열을 대응 대체문자열로 바꿈. 예: `BACKUP AS COPY DB_FILE_NAME_CONVERT=('dbs','newdbs') TABLESPACE users;`는 `/disk1/dbs/users.dbf`를 `/disk1/newdbs/users.dbf` 형태로 생성함.
  - 검증 항목: Oracle Database 19c Backup and Recovery Reference 4.8 `fileNameConversionSpec`에서 BACKUP, CONVERT, DUPLICATE의 출력 파일명 생성에 사용함을 확인함. 여러 쌍은 첫 일치 항목이 적용되며, ASM 또는 일반 파일시스템의 OMF 원본은 이 절로 새 OMF 이름을 만들 수 없으므로 `FORMAT` 등으로 위치를 지정하고 데이터베이스가 이름을 생성하게 해야 함.

  - 질문 맥락: `Tab`으로 자동완성 후보를 연 뒤 `↓` 이동은 되지만 `↑`로 이전 후보에 돌아가지 않는 현상을 수정해 달라는 요청.
