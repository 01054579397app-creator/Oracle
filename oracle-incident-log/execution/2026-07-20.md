- 주제: Data Pump에서 DAMO 스키마 제외
- 질문 맥락: `EXCLUDE=SCHEMA:"='DAMO'"` 형식 사용 가능 여부.
- 오류 메시지: 없음
- 원인 가설: FULL 모드의 expdp 또는 impdp에서 SCHEMA object path에 name clause를 적용하면 특정 스키마를 제외할 수 있음. 셸에서는 따옴표 해석에 주의해야 함.
- 권장 조치: parfile에 `EXCLUDE=SCHEMA:"='DAMO'"`를 기재하고 `FULL=Y` 작업에서 사용. 여러 스키마는 `IN ('A','B')` 사용.
- 검증 항목: Data Pump 로그에서 DAMO 스키마 및 소속 객체가 처리되지 않았는지 확인하고, 대상 DB의 DBA_USERS와 DBA_OBJECTS로 재확인.
