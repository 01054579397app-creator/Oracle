- 주제: ASMCA silent ADVM 볼륨 생성 명령 무응답 시 로그 확인
- 질문 맥락: grid 사용자로 `asmca -silent -createVolume -volumeName arch_fs -volumeDiskGroup ARCH_HOME -volumeSizeGB 10` 실행 후 명령이 끝나지 않는 상황에서 로그 위치를 확인하려 함.
- 에러 메시지: 출력 없이 멈춘 상태이며 구체적인 ORA/ASMCMD 오류는 아직 확인되지 않음.
- 원인 가설: ASMCA 작업 진행 또는 내부 ASM/Clusterware 호출 대기일 수 있으므로, 먼저 ASMCA 로그와 프로세스 상태를 확인해야 함. 단순히 멈췄다는 사실만으로 원인을 확정할 수 없음.
- 권장 조치: `$ORACLE_BASE/cfgtoollogs/asmca/<hostname>/asmca.log`와 최신 `cfgtoollogs/asmca` 파일을 확인하고, 별도 터미널에서 ASMCA 및 자식 프로세스와 ASM alert log를 점검함.
- 검증 항목: `asmcmd volinfo -G ARCH_HOME arch_fs`, `asmcmd volinfo --all`, `ps -ef | grep asmca`로 생성 여부와 실행 상태를 확인함.
