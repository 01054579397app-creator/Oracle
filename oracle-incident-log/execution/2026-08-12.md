- 주제: Echelon ECL_DECRYPT 결과가 암호문 그대로 반환되는 SQL 형태
- 질문 맥락: SQL*Plus 셸 스크립트에서 ECL_ENCRYPT 결과를 변수로 받아 ECL_DECRYPT에 전달했으나 암호문이 그대로 출력됨.
- 오류 메시지: ORA 오류 없음. `select 'Decrypt Text : '||ecl_decrypt('<cipher>') from dual`에서 입력 암호문이 그대로 반환됨.
- 원인: DB의 ECHELON.ECL_DECRYPT 함수는 입력을 그대로 반환하는 자리표시자이며, Echelon 프록시가 SQL을 인식할 때만 실제 복호화한다. 함수 결과 앞에 문자열 연결 연산자를 둔 형태는 프록시가 복호화 함수 호출로 인식하지 못했다. 변수는 32바이트로 공백 없이 정상임을 바이트 단위로 확인함.
- 권장 조치: ECL_DECRYPT를 SELECT 최상위 표현식으로 단독 호출한다. 같은 줄에 라벨이 필요하면 SQL*Plus `COLUMN ... NEW_VALUE ... NOPRINT`로 결과를 받은 뒤 `PROMPT`로 출력한다.
- 검증 항목: 단독 호출은 평문 `123`을 반환했고, 문자열 연결 호출은 암호문을 그대로 반환했다. `COLUMN DEC_TEXT NEW_VALUE DEC_TEXT NOPRINT` 후 `PROMPT Decrypt Text : &DEC_TEXT`는 `Decrypt Text : 123`을 출력했다.
