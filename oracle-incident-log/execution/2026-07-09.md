## [2026-07-09 00:00 KST] TTS migration script review

- 주제: TTS 전체 진행 스크립트 사전 검토
- 질문 맥락: 사용자가 TTS 전환 절차표와 `01_check_tts.sh`부터 `13_change_valid.sh`까지의 세부 스크립트에서 문제될 부분을 지적해 달라고 요청함.
- 에러 메시지: 현재 실행 에러가 아니라 실행 전 리뷰임.
- 원인 가설: 스크립트가 ASIS/TOBE SID를 명시하지 않은 구간, `activate standby database`, target placeholder tablespace 삭제, 전체 사용자 DBA 권한 부여, SYS 객체 수동 생성, plaintext DB link 계정, 실패 후 계속 진행하는 구조를 포함하고 있어 실제 전환 시 장애/보안/복구 리스크가 큼.
- 권장 조치: 각 단계 시작 시 기대 DB/SID/role/open_mode를 검증하고 실패 시 중단하도록 만들며, target TTS import의 `transport_datafiles`는 TOBE에서 접근 가능한 실제 파일 경로로 생성한다. 전체 사용자 DBA 부여와 SYS 객체 대량 생성은 제거하거나 승인된 예외 목록으로 제한한다. DB link 계정은 전용 최소권한 계정으로 교체하고 비밀번호는 스크립트에 남기지 않는다.
- 검증 항목: ASIS/TOBE character set, endian, timezone file, option/component 비교, `TRANSPORT_SET_VIOLATIONS` 0건, Data Pump/RMAN 로그의 ORA/EXP/IMP/RMAN 오류 0건, target tablespace READ WRITE 상태, invalid/missing object 비교 쿼리의 owner/object_type 포함 여부.
