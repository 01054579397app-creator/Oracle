- [2026-07-13 14:15:22] Oracle Incident - execution
  - 질문 맥락: Oracle Data Pump INCLUDE 목록에 Network ACL과 ACE를 이관할 수 있는 Object Path가 있는지 문의
  - 에러 메시지: 오류 없음. Data Pump 메타데이터 Object Path 확인 문의
  - 원인 가설: Full Data Pump 모드의 DATABASE_EXPORT_OBJECTS에는 NETWORK_ACL Object Path가 있으며 Host ACL, Wallet ACL 및 ACE가 NACL export/import 내부 객체로 함께 처리된다. ACE와 ACL은 별도 INCLUDE 이름이 아니고 NETWORK_ACL 하나로 묶인다. Schema/Table 모드에는 일반적으로 사용할 수 없으므로 실제 DB 뷰 조회가 기준이다.
  - 권장 조치: AS-IS PDB에서 DATABASE_EXPORT_OBJECTS와 SCHEMA_EXPORT_OBJECTS를 조회한다. NETWORK_ACL이 확인되면 expdp FULL=Y INCLUDE=NETWORK_ACL로 별도 덤프하고, TO-BE에서 사용자/역할 생성 후 import한다. Wallet OS 파일은 Data Pump에 포함되지 않으므로 별도 복사한다.
  - 검증 항목: Export 및 Import 로그에서 NETWORK_ACL, NACL$_ACE, NACL$_HOST, NACL$_WALLET 처리를 확인하고 AS-IS/TO-BE의 DBA_HOST_ACLS, DBA_HOST_ACES, DBA_WALLET_ACLS, DBA_WALLET_ACES 결과를 비교한다.
