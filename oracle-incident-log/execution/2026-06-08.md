# Oracle Incident Log - execution


- [2026-06-08 11:01:54] Oracle Incident - execution
  - 질문 맥락: DBA_DATA_FILES/DBA_FREE_SPACE 기반 tablespace 사용률 80% 이상 조회 SQL 수정
  - 에러 메시지: ORA-00904 가능: Y.USED_PER 식별자 부적합
  - 원인 가설: inner query에서 사용률 alias를 USDE_PER로 생성했지만 outer query에서 USED_PER로 참조했고, 사용률 계산식이 *1000으로 되어 있어 퍼센트 값이 잘못 계산됨. DBA_FREE_SPACE inner join 사용 시 free extent가 없는 tablespace가 누락될 수 있음
  - 권장 조치: datafile 총량과 free space 총량을 각각 집계한 뒤 LEFT JOIN하고, NVL(free_mb,0) 및 *100 기준으로 사용률 계산
  - 검증 항목: USED_PER alias 일치, USED(%) 계산식, free space 없는 tablespace 포함 여부, MOUNT 상태가 아닌 OPEN 상태에서 실행
