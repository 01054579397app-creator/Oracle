# Oracle Incident Log - errors

- [2026-05-14 13:26:31] Oracle Incident - errors
  - 주제: RMAN `restore archivelog all` 수행 중 archived log 백업 미존재 오류
  - 질문 맥락: RMAN에서 `restore archivelog all;` 실행 직후 `RMAN-03002`, `RMAN-06026`, `RMAN-06025`가 발생했고, RAC thread 1/2의 sequence 1~10 archived log 백업을 찾지 못한다고 출력됨.
  - 에러 메시지: `RMAN-06026: some targets not found - aborting restore`, `RMAN-06025: no backup of archived log for thread 1/2 with sequence ... found to restore`.
  - 원인 가정: `restore archivelog all`은 RMAN repository/controlfile에 기록된 모든 archived log를 대상으로 삼기 때문에, 실제 복구에 필요하지 않은 오래된 sequence까지 복원하려다 해당 archivelog backup piece가 없어 중단된 것으로 판단. RAC 환경이라 thread 1과 thread 2의 archived log가 모두 대상에 포함됨.
  - 권장 조치: 전체 복원이 아니라 필요한 SCN/time/sequence 범위로 제한해 `restore archivelog from scn ...`, `restore archivelog from time ...`, 또는 thread별 `from sequence ... until sequence ... thread ...` 형식으로 복원한다. 먼저 `list backup of archivelog`, `crosscheck backup`, `list expired backup`, `list archivelog all`로 RMAN metadata와 실제 backup piece 상태를 확인한다.
  - 검증 항목: `list backup of archivelog sequence 1 thread 1;`, `list backup of archivelog sequence 1 thread 2;`, `list backup of archivelog from scn <필요_SCN>;`, `restore archivelog from scn <필요_SCN> validate;`, `recover database preview;`.
