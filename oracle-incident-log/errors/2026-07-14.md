# Oracle Incident Log - errors


- [2026-07-14 08:55:54] Oracle Incident - errors
  - 질문 맥락: Data Pump에서 Scheduler PROCOBJ 생성 중 SYSTEM.SCHEDULER_JOB_ARGS_TMP 부재와 ORA-39126 발생
  - 에러 메시지: ORA-39083, ORA-00942: SYSTEM.SCHEDULER_JOB_ARGS_TMP table or view does not exist, PLS-00364, ORA-39126 KUPW$WORKER.SEND_TRACE_MSG, ORA-06502 character string buffer too small
  - 원인 가설: Scheduler Job 인수 복원용 내부 스테이징 테이블을 찾지 못해 4개 Job 생성 블록이 실패했다. 동일 오류가 두 번 반복되어 PROCOBJ와 SCHEDULER 메타데이터를 분할 또는 중복 import한 영향 가능성이 높다. ORA-39126은 이 실패 메시지를 처리하던 Data Pump Worker의 2차 내부 오류다.
  - 권장 조치: SYSTEM 테이블을 수동 생성하지 않는다. 대상 Job 존재 여부와 SYSTEM.SCHEDULER_JOB_ARGS_TMP 존재 여부를 확인하고, SQLFILE로 덤프 메타데이터를 점검한다. PROCOBJ/SCHEDULER 중복 import를 제거하여 Scheduler 메타데이터를 한 번만 재실행한다. 깨끗한 단일 재실행에서도 ORA-39126이 재현되면 19.24보다 최신 적용 가능 RU와 Oracle Support 버그를 확인한다.
  - 검증 항목: DBA_SCHEDULER_JOBS와 DBA_SCHEDULER_JOB_ARGS에서 4개 Job 및 인수 확인; import 로그에서 ORA-39083/39126 부재와 Job enabled 상태 확인; 소스/대상 NLS 문자셋 및 한글 주석 표시 확인
