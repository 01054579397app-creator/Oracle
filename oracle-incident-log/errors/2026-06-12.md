  - 질문 맥락: RMAN HIGH 압축 백업을 실행했는데 DBA_FEATURE_USAGE_STATISTICS에 안 잡힘. 실행 로그는 CONFIGURE MAXSETSIZE TO 100m 후 BACKUP AS compressed BACKUPSET DATABASE 실패, RMAN-06183 datafile sysaux larger than MAXSETSIZE 발생.
  - 에러 메시지: RMAN-03002: failure of backup command at 06/12/2026 15:51:43; RMAN-06183: datafile or datafile copy +DATA/PRMSDB/DATAFILE/sysaux.265.1233153593 (file number 2) larger than MAXSETSIZE
  - 원인 가설: MAXSETSIZE는 backup set 전체 크기 제한이며 100M로 설정하면 100M보다 큰 데이터파일을 포함하는 backup set을 만들 수 없다. SYSAUX 데이터파일이 100M보다 커서 백업이 실제 생성되지 않았고, 따라서 RMAN HIGH/압축 사용 흔적도 feature usage에 반영되지 않는다. 또한 COMPRESSION ALGORITHM HIGH 설정이 없으면 AS COMPRESSED BACKUPSET은 기본 알고리즘(BASIC)을 사용할 수 있다.
  - 권장 조치: MAXSETSIZE를 CLEAR하거나 가장 큰 데이터파일보다 크게 설정한다. 출력 backup piece 크기를 제한하려는 목적이면 MAXSETSIZE가 아니라 채널의 MAXPIECESIZE를 사용한다. 큰 데이터파일을 섹션 단위로 쪼개려면 SECTION SIZE를 사용한다. HIGH를 명시하려면 CONFIGURE 또는 SET COMPRESSION ALGORITHM HIGH 후 백업을 성공 완료시킨다.
  - 검증 항목: RMAN SHOW ALL, LIST BACKUP SUMMARY, LIST BACKUP OF DATAFILE 2, SELECT file#, bytes/1024/1024 FROM v$datafile WHERE file#=2, DBA_FEATURE_USAGE_STATISTICS의 compression/RMAN 관련 항목을 백업 성공 후 재조회한다.
