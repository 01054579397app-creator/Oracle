- 주제: Oracle Database용 NFS rsize/wsize 및 Direct NFS wtmax 설명
- 질문 맥락: Oracle 문서의 rsize=32768, wsize=32768, vers=3 마운트 예시와 Direct NFS의 wtmax 문구가 무엇을 뜻하는지 문의.
- 오류 메시지: 없음
- 원인 가설: rsize/wsize를 Oracle 초기화 파라미터로 오해할 수 있으나, 실제로는 OS NFS 클라이언트의 읽기/쓰기 요청 크기 마운트 옵션임.
- 권장 조치: 커널 NFS 사용 시 /etc/fstab 또는 mount 명령에 서버 권고 옵션을 지정하고, Oracle Direct NFS 사용 여부와 스토리지 벤더 권고값을 구분하여 적용.
- 검증 항목: mount 또는 nfsstat -m으로 협상된 rsize/wsize 확인. Direct NFS 사용 시 V$DNFS_SERVERS와 alert log로 활성화 여부 확인.
