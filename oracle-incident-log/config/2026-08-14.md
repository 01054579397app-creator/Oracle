- [2026-08-14 15:21:37] Oracle Incident - config
  - 질문 맥락: Oracle GoldenGate 운영 계정의 비밀번호를 주기적으로 변경할 때 DB 계정과 Credential Store를 어떤 순서로 전환해야 하는지 확인
  - 현재 구성: NDBHOME1의 OGG Classic 19.1.0.0.4 Credential Store 기본 도메인에 `src=ggadmin@oggsrc`, `trg=ggadmin@oggtrg`가 있다. `EXT1`은 `USERIDALIAS src`, `rep1.prm`은 `USERIDALIAS trg`를 사용한다. Manager에는 `AUTOSTART ER *`와 `AUTORESTART ER *, WAITMINUTES 1, RETRIES 10`이 설정되어 있다. 현재 REP1 그룹은 GGSCI에 등록되지 않았고 EXT1은 별도 trail 등록 오류로 ABENDED 상태다. `oggsrc`는 192.168.40.150:1521의 DMRMS, `oggtrg`는 192.168.40.191:11521의 DMHOME을 가리킨다.
  - 권장 순서: 소스와 타깃을 동시에 바꾸지 말고 alias별로 한쪽씩 처리한다. 무중단 우선이면 전용 DB 프로파일에 `PASSWORD_ROLLOVER_TIME`을 설정하고 DB에서 새 비밀번호로 변경하여 구/신 비밀번호 병행 기간을 시작한 다음, OGG 서버에서 `ALTER CREDENTIALSTORE REPLACE USER ggadmin@<tns_alias> ALIAS <alias>`를 PASSWORD 절 없이 실행해 숨김 프롬프트로 새 비밀번호를 저장한다. 이어 `DBLOGIN USERIDALIAS <alias>`를 검증하고 영향 프로세스의 재연결/재시작 검증 후 롤오버 기간을 종료한다. 롤오버를 사용하지 않으면 AUTORESTART를 고려해 영향 Extract/Replicat을 명시적으로 STOPPED로 통제하고 DB 비밀번호 변경, Credential Store REPLACE, DBLOGIN 검증, 프로세스 START 순서로 짧은 점검 시간에 수행한다.
  - 현재 환경 적용: 활성 Replicat이 없으므로 `trg`를 먼저 변경·DBLOGIN 검증한 뒤 `src`를 변경하는 것이 안전하다. EXT1은 현재 ABENDED이므로 trail 등록 문제를 해결해 시작하기 전에 `src` 갱신을 완료한다. 설치된 GGSCI 도움말은 `PASSWORD` 절을 쓰면 비밀번호가 화면에 평문으로 표시되므로 생략하고 숨김 프롬프트를 쓰도록 명시한다.
  - 검증 항목: 변경 전 alias 소비 프로세스와 DB 프로파일 확인, `DBLOGIN USERIDALIAS src/trg` 성공, `INFO CREDENTIALSTORE`의 alias/userid 유지, 프로세스 RUNNING, report/ggserr.log에 ORA-01017 또는 OGG 로그인 오류 없음, checkpoint/lag/trail 증가 확인. 비밀번호 자체는 로그나 명령 이력에 기록하지 않는다. 이번 확인에서는 DB 비밀번호, Credential Store, OGG 프로세스를 변경하지 않았다.
