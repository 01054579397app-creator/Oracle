# Oracle Incident Log - config


- [2026-08-12 14:07:14] Oracle Incident - config
  - 질문 맥락: Oracle Linux 9.7 서버에서 ISO 로컬 저장소로 필수 패키지를 설치하는데 DNS 오류가 발생함
  - 에러 메시지: file:///media AppStream/BaseOS를 구성했지만 DNF가 DNS 관련 원격 저장소 오류를 출력함
  - 원인 가설: 로컬 저장소 외에 ol9_UEKR8 원격 저장소가 enabled 상태라 DNF가 모든 활성 저장소 메타데이터를 함께 조회함
  - 권장 조치: 오프라인 설치 시 dnf --disablerepo=* --enablerepo=AppStream --enablerepo=BaseOS install ... 형식으로 로컬 저장소만 지정한다. NDBHOME2는 /dev/sr0 마운트와 local.repo 생성부터 수행한다.
  - 검증 항목: NDBHOME1에서 ISO는 /media에 정상 마운트되고 repomd.xml이 존재했다. 로컬 저장소만 지정한 --assumeno 해석은 완료되었으며 요청 패키지는 전부 이미 설치된 상태였다. NDBHOME2는 /media 미마운트 및 local.repo 미생성 상태였다.
