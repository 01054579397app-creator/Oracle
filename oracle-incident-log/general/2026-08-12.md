- 주제: 1521 경유와 11521 직접 접속에서 ECL_ENCRYPT 결과가 다른 이유
- 질문 맥락: 같은 `select echelon.ecl_encrypt('1111') from dual`이 1521에서는 암호문, 11521에서는 원문을 반환하는 원리를 이해하기 쉽게 설명함.
- 오류 메시지: 해당 없음.
- 원인 가설: 1521은 Echelon Java 프록시가 수신하므로 함수 표식을 인식해 실제 암호화를 수행한다. 11521은 Oracle Listener 직접 접속이므로 Echelon을 거치지 않으며, DB에 생성된 자리표시자 ECL_ENCRYPT가 입력값을 그대로 반환한다.
- 권장 조치: 문서에서 ECL 함수는 Oracle 내부 암호화 구현이 아니라 Echelon 프록시가 인식하는 호출 표식이라고 설명한다. 실제 암호화 데이터를 저장하는 INSERT/UPDATE와 단순 SELECT 함수 테스트도 구분한다.
- 검증 항목: DBA_SOURCE에서 ECHELON.ECL_ENCRYPT와 ECL_DECRYPT가 `RETURN I_value`로 정의된 것을 확인했고, 1521 경유 시 암복호화되며 11521 직접 접속 시 입력값이 그대로 반환되는 것을 확인함.
