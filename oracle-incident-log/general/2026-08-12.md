- 주제: Oracle 환경의 Echelon V4.5 동작 원리
- 질문 맥락: RAC 두 노드 설치와 함수 테스트를 바탕으로 에이전트, 관리도구, RSA, 데이터 암호키, DB 함수의 관계를 설명함.
- 오류 메시지: 해당 없음.
- 원인 가설: 해당 없음. 제품 구조 설명.
- 권장 조치: 사용자 SQL은 Echelon Secure Proxy를 경유하게 하고, 관리도구 세션은 노드별로 구성하되 RAC 공유 데이터를 처리하는 데이터 암호키는 두 노드에서 동일하게 유지한다. 관리통신용 RSA 키 쌍과 데이터 암호키를 구분한다.
- 검증 항목: 현재 환경에서 Echelon Java가 1521을 수신하고 Grid Listener 11521로 전달함. 관리 포트는 29995임. DB의 ECL_ENCRYPT/ECL_DECRYPT는 입력값을 반환하는 자리표시자이고 프록시가 인식한 호출에서만 실제 암복호화됨. RSA 공개키 삭제 시 에이전트가 즉시 종료했으며 원본 키 쌍 복원 후 양 노드가 기동됨.
