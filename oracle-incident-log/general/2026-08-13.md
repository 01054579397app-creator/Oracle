# Oracle Incident Log - general


- [2026-08-13 14:23:55] Oracle Incident - general
  - 질문 맥락: 데이터파일 앞부분이 비어 있고 새 테이블만 뒤쪽을 사용하는데 왜 RESIZE가 불가능한가
  - 에러 메시지: 데이터파일 후미에 사용 중인 extent가 있어 목표 크기까지 축소 불가
  - 원인 가설: RESIZE가 파일 내부 블록을 자동 압축하거나 앞쪽으로 이동한다고 오해할 수 있으나, Oracle RESIZE는 후미의 연속된 빈 영역만 절단하며 세그먼트를 재배치하지 않음
  - 권장 조치: TAF_TEST의 OWNER, TABLESPACE_NAME, FILE_ID, extent 시작과 끝 위치를 확인한 후 테이블 MOVE 및 인덱스 재구성 여부를 결정한다. SYSTEM 또는 SYSAUX라면 무작정 이동하지 않는다.
  - 검증 항목: MOVE 후 DBA_EXTENTS의 파일 HWM이 내려갔는지 재조회한 다음 HWM보다 큰 값으로 RESIZE한다.
